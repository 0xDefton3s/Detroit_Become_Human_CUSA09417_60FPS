# Detroit: Become Human - 60 FPS Patch (CUSA09417)

---

## English

There was already another patch, but I don't know if it works, and it wasn't available for the CUSA09417 version. I ported and adapted it for the latest v1.08 update, and it works without any issues. I'm using it on PS5 13.60 Cheatrunner. Sharing it in case anyone wants to use it. Just note that I haven't tested it on CUSA00717.

### Information
- **Game:** Detroit: Become Human
- **Title ID:** CUSA09417
- **Target App Version:** v1.08 (also includes pattern scan profile)
- **Tested Environment:** PS5 (FW 13.60) via Cheatrunner

### Installation

#### PS5 (Cheatrunner)
1. Copy `CUSA09417.xml` to:
   ```text
   /data/cheatrunner/patches/xml/CUSA09417.xml
   ```
2. Open the Cheatrunner dashboard or use the in-game hotkey to enable the **60 FPS Unlock** patch.

#### PS4 (GoldHEN)
1. Copy `CUSA09417.xml` to:
   ```text
   /user/data/GoldHEN/patches/xml/CUSA09417.xml
   ```
2. Enable the patch from the GoldHEN Patch Settings / Cheat Manager menu.
